## About the Project

**HIPPO'S MENU is a GSC-based mod menu for the original Call of Duty: Modern Warfare 2 (2009) on PC.**

**The project was created as a tribute to the old modded lobbies that made MW2 memorable.**

**The menu brings together player modifications, bot controls, weapon customization, object spawning, visual customization, additional game modes, and lots of other fun features in one menu system.**

**The goal is simple: recreate some of that classic MW2 modded-lobby experience while offering a wide variety of features to experiment with.**

## Installation

### Requirements

- Call of Duty: Modern Warfare 2 (2009) for PC.
- A GSC-compatible mod environment.
- The project scripts included in this repository.

### Script Setup

1. Download or clone the repository.
2. Place the GSC scripts into the appropriate locations for your GSC-compatible mod environment.
3. Make sure the main menu and its required helper scripts are included.
4. Include the additional scripts for the features you want to use.
5. Configure the menu using `hippo_menu.cfg` where supported by your setup.
6. Launch the game through your mod environment and test the menu.

**Important:** Exact installation paths and loading procedures depend on the GSC mod environment being used. Follow the instructions for your particular loader.

### Required and Optional Scripts

| File                 | Purpose                                |
| -------------------- | -------------------------------------- |
| `hippo_menu.gsc`     | Main menu and initialization           |
| `_hippo_actions.gsc` | Main menu feature actions              |
| `_hippo_ui.gsc`      | Menu interface and visual presentation |
| `hippo_extras.gsc`   | Additional player features and perks   |
| `hippo_modes.gsc`    | Gun Game and One in the Chamber        |
| `hippo_heli.gsc`     | Optional experimental helicopter       |
| `hippo_menu.cfg`     | Configuration and key bindings         |

The helicopter functionality depends on the optional `hippo_heli.gsc` script. If you do not want to use that feature, the optional script can be left out.
